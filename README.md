# CHP Heat Guardian — independent website

This folder is a complete static site. Open index.html locally or upload these files to a static host. No build command, API key, Python server or OpenAI runtime is required.

GitHub Pages: upload the contents of this folder to a repository root. Settings → Pages → Deploy from a branch → main → /(root) → Save. Use the address returned by GitHub.

Netlify: sign in, open https://app.netlify.com/drop, and drop the folder containing index.html. Use the address returned by Netlify.

The reference data are real 2023 TA-5 historical observations. data.js contains 779 replay rows, models and stored SE evidence. Visitors can download them if the site is public. The raw workbook is not included.

The interface preserves heat monitoring, CHP flows, sensor-offset experiments, D0 estimates, cost scenarios and JSON exports. Cost values are scenario calculations; the site is a research prototype.

Development used AI assistance. Rehosting does not alter authorship.
